# Free Fire Sensitivity Generator

A simple web app that suggests starting sensitivity settings for Free Fire based on your device, screen size, performance, play style, finger setup and swipe speed.

It outputs values (1-200) for General, Red Dot, 2x Scope, 4x Scope, Sniper Scope, AWM Scope and Free Look. You can copy them or download them as a text file.

> These are suggested starting points, not official Garena numbers. Test in the Training Ground and adjust by 3 to 5 points at a time.

## Run locally

Open `index.html` in any browser. No install or build step.

## Upload to GitHub

1. Create a new repository on github.com (for example `free-fire-sensitivity`).
2. Click **Add file > Upload files**, drop in `index.html` and `README.md`, then **Commit changes**.

## Put it online (GitHub Pages)

1. In the repo, go to **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
3. After a minute your app is live at `https://YOUR-USERNAME.github.io/free-fire-sensitivity/`.

## Install as an app (PWA)

After deploying with GitHub Pages, open the link on your phone:
- **Android (Chrome):** menu (three dots) > **Install app** or **Add to Home screen**.
- **iPhone (Safari):** Share > **Add to Home Screen**.

It then opens full screen like a normal app and works offline.

## Make an APK (optional)

Go to https://www.pwabuilder.com, paste your GitHub Pages link, and choose **Package for stores > Android** to download an APK.
